# Domini DNA

I domini sono bounded context applicativi, non applicazioni indipendenti per definizione.

- `travel` — Travel DNA, temporaneamente collegato al repository TDNA durante la migrazione history-aware.
- `shopping` — previsto dopo la stabilizzazione dei contratti comuni.
- `social` — previsto come dominio di interessi e comunità contestuali.
- `economy` — previsto come servizio separato di gestione economica personale e familiare.
- `commons` — chat geografiche, gruppi e sottoscrizioni; può diventare un modulo di piattaforma se usato da più domini.

Le decisioni trasversali vivono nella documentazione principale. I documenti di un dominio non ridefiniscono contratti comuni.
